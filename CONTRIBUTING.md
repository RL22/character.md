# Contributing

Thanks for your interest in improving Character.md.

This repo is meant to stay beginner-friendly while still being useful for advanced AI image workflows.

## Good contributions

- New prompt templates
- Better consistency checks
- More use cases for creators, founders, and marketers
- Improved install instructions
- Examples for different image models
- Accessibility and clarity improvements to the landing page

## How to contribute

1. Fork the repo.
2. Create a branch.
3. Make your changes.
4. Open a pull request with a short explanation of what changed and why.

## Contribution principles

- Keep instructions practical.
- Avoid unnecessary jargon.
- Prefer reusable systems over one-off prompts.
- Keep beginners in mind.
- Do not include copyrighted brand assets, visible logos, or private reference photos.
