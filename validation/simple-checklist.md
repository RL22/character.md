# Simple Consistency Checklist

Use this after every image batch.

The goal is not perfection. The goal is to keep the same person recognizable across different contexts.

## The 3-question check

1. **Face:** Does this still look like the same person?
2. **Hair + beard:** Are the hairline, beard length, and facial hair shape consistent?
3. **Vibe:** Does this feel like the intended person, or does it feel like generic stock photography?

If an image passes all three, keep it.

If it fails one, refine and regenerate.

---

## Beginner workflow

```txt
Generate 6–8 images
↓
Keep the 2–4 strongest
↓
Notice what drifted
↓
Tighten character.md
↓
Regenerate
```

---

## What to update when things drift

- Face looks different → strengthen face shape, jawline, eyes, proportions
- Hair changes → strengthen hairline and density language
- Beard changes → add length in millimeters and density description
- Skin looks too smooth → add natural texture and no-airbrushing language
- Image feels generic → strengthen wardrobe, environment, and cultural signal layer
