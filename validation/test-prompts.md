# Test Prompts

Use these to stress test your Character DNA.

A strong character file should hold identity across lighting, wardrobe, angle, and environment changes.

---

## Test 1: Clean headshot

```txt
[Character DNA]
[Face Lock Snippet]

Clean headshot, neutral background, direct eye contact, 85mm lens, soft studio lighting, natural skin texture, no visible brands.
```

## Test 2: Café lifestyle

```txt
[Character DNA]
[Face Lock Snippet]

Working in a warm café with laptop and coffee mug, natural window light, 50mm lens, candid composition, lived-in environment, not a stock photo.
```

## Test 3: Side profile

```txt
[Character DNA]
[Face Lock Snippet]

Side profile portrait, thoughtful expression, minimal background, natural skin texture, 85mm lens, soft directional lighting.
```

## Test 4: Low-key cinematic

```txt
[Character DNA]
[Face Lock Snippet]

Cinematic low-key founder portrait, side lighting, subtle rim light, deeper shadows, 35mm lens, off-center composition, no visible logos.
```

```txt
Wearing workwear-inspired outerwear over a clean neutral tee, relaxed fit, beanie, no visible logos. Standing in an industrial coworking space with texture and depth.
```
