# Test Prompts

Use these to test your Character DNA.

Start with the identity-safe tests. Only run the harder stress tests after anchor and transition portraits pass review.

---

## Test 1: Clean headshot

```txt
[Character DNA]
[Face Lock Snippet]

Clean headshot, neutral background, direct eye contact, 85mm lens, soft studio lighting, natural skin texture, no visible brands.
```

## Test 2: Café lifestyle

```txt
[Character DNA]
[Face Lock Snippet]

Waist-up café transition portrait, face large and sharp, slight three-quarter angle, both eyes visible, laptop and coffee mug nearby, natural window light, 70mm lens, lived-in environment secondary to the face, not a stock photo.
```

## Test 3: Desk transition

```txt
[Character DNA]
[Face Lock Snippet]

Waist-up desk transition portrait, face dominant, front-facing or slight three-quarter angle, no hat, no headphones, dual monitors and laptop in background, 70mm lens, clean natural light, photorealistic.
```

## Test 4: Single-scene lifestyle

```txt
[Character DNA]
[Face Lock Snippet]

Working at a warm cafe table with laptop, coffee mug, notebook, textured wall, and natural window light. Face remains large enough to judge identity, slight three-quarter angle, 70mm lens, soft background blur, no dramatic shadows, not a stock photo.
```

## Harder stress tests

Run these only after the identity-safe tests pass.

### Side profile

```txt
[Character DNA]
[Face Lock Snippet]

Side profile portrait, thoughtful expression, minimal background, natural skin texture, 85mm lens, soft directional lighting.
```

### Low-key cinematic

```txt
[Character DNA]
[Face Lock Snippet]

Cinematic founder portrait, controlled shadows that do not hide facial structure, subtle rim light, 70mm lens, off-center composition, no visible logos.
```

### Motion / candid

```txt
[Character DNA]
[Face Lock Snippet]

Walking through a coworking space while holding a laptop and coffee mug, natural motion, slight imperfect framing, 70mm lens, face still visible enough to judge identity, natural light, photorealistic.
```
