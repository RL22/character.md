# Image Progression

A strong character system usually improves in stages.

## Stage 1: Reference photos

Start with real reference photos that show:

- Front view
- Side profile
- Three-quarter angle
- Natural expression
- Hair and facial hair clearly

## Stage 2: Baseline headshot

Generate a simple controlled headshot first.

Purpose:

- Lock identity
- Test facial structure
- Test hairline and beard consistency
- Create a visual anchor

## Stage 3: Refined headshot

Adjust small details:

- Under-eye treatment
- Skin texture
- Beard length
- Expression
- Wardrobe

## Stage 4: Lifestyle v1

Move into real-world scenes:

- Café
- Coworking space
- Desk setup
- Podcast setup

At this stage, identity drift often appears.

## Stage 5: Cultural signal layer

If images feel like stock photos, add personal context:

- Style references
- Local/cultural cues
- Wardrobe tension
- Lived-in environments
- Slightly imperfect composition

## Stage 6: Batch refinement

Generate 6–12 images, keep the strongest, and use drift notes to update `character.md`.
