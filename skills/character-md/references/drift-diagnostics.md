# Drift Diagnostics

Use this file when images start looking inconsistent.

## Face shape drift

Symptoms:

- Face becomes wider or narrower
- Jawline softens
- Chin changes shape
- Eyes shift position

Fix:

```txt
Reinforce: oval face shape, defined jawline, slightly narrow chin, same face proportions, no variation in bone structure.
```

## Hairline drift

Symptoms:

- Hairline becomes too sharp
- Hairline fills in too much
- Crown density changes
- Temples look different

Fix:

```txt
Reinforce: very short cropped hair, lower density at crown, slight recession at temples, natural hairline, not artificially filled.
```

## Beard drift

Symptoms:

- Beard becomes too full
- Beard disappears
- Neckline changes
- Edges become too sharp

Fix:

```txt
Reinforce: short beard, 3–5mm length, natural density variation, slightly fuller on chin, clean neckline, no hyper-defined barber edges.
```

## Skin drift

Symptoms:

- Skin looks plastic
- Face becomes too glossy
- Under-eye detail disappears completely
- Age changes

Fix:

```txt
Reinforce: natural skin texture, slight under-eye shadows retained, no airbrushing, no plastic smoothing, realistic tone variation.
```

## Stock-photo drift

Symptoms:

- Image feels too clean
- Environment looks staged
- Outfit looks generic
- Subject feels like a model instead of a person

Fix:

```txt
Add: lived-in environment, slightly imperfect composition, natural candid moment, workwear/streetwear influence, culturally grounded, not a stock photo.
```

## Brand drift

Symptoms:

- Style becomes too corporate
- Style becomes too influencer-like
- Scene loses the intended personality

Fix:

```txt
Reinforce the cultural signal layer: Black tech founder from Oakland, creative and technical hybrid, hypebeast meets builder, quiet confidence, not performative.
```
